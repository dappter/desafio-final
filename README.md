# SI Code Week 2026 · Desafio Final · Sistema em Crise

Mini-sistema da loja online do **Mercadão do Cariri**. Ele funciona há anos,
mas três chamados chegaram juntos. Sua missão: **corrigir os três** sem
quebrar o resto, e escrever o **laudo técnico** que o diretor pediu.

Este repositório é seu. Só você e a Coordenação conseguem ver.

| Arquivo | O que é |
|---|---|
| `loja/banco.py` | banco de dados e dados de exemplo — **está correto, não mexa** |
| `loja/precos.py` | cálculo do total do pedido |
| `loja/relatorios.py` | relatório de clientes |
| `loja/clientes.py` | busca de cliente por e-mail |
| `REGRAS.md` | **como o sistema deve se comportar** (leia antes de mexer) |
| `CHANGELOG.md` | histórico do sistema |
| `tests/test_exemplos.py` | testes de exemplo (fumaça) |

## Rodar os testes de exemplo

```
python -m unittest
```

Python 3.12, só com a biblioteca padrão. Os testes de exemplo passam no
código como ele está: eles cobrem o comportamento básico, **não** os três
defeitos. Achar e corrigir os defeitos é com você.

## Entregar

1. Corrija o código e faça commit (e push).
2. Copie o endereço da página do commit, ou o SHA, e cole no formulário do
   Desafio Final, com o **laudo** e a **justificativa**.

Vale o commit que você informar, não o que vier depois. **O Final fecha às 22h00.**
